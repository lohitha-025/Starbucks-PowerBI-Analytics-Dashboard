# Starbucks Power BI Analytics Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze Starbucks beverage data and generate meaningful business insights.

The dashboard focuses on beverage categories, nutritional information, caffeine content, and beverage distribution.

## 🎯 Objectives

- Analyze beverage categories
- Compare calories, sugar, and caffeine levels
- Identify beverages with high caffeine content
- Explore beverage category distribution
- Present insights through an interactive Power BI dashboard

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Microsoft Excel
- Data Visualization
- Data Analysis

## 📈 Dashboard Highlights

- Total beverage analysis
- Average sugar and calorie analysis
- Average caffeine by beverage category
- Top 5 highest-caffeine beverages
- Beverage category distribution
- Interactive filters and visualizations
